## Project Summaries

### 1. RESTful API Practical

The RESTful project is a Fire Extinguisher Management System built using a microservices architecture. It includes services for authentication, users, fire extinguishers, inspections, maintenance, notifications, reports, audit logs, and an API gateway. A React frontend communicates with the backend services through the gateway.

Key features include JWT authentication, role-based access control, service-based API design, Prisma database schemas, OpenAPI documentation, reporting, and Docker-based deployment.

### 2. Java Practical

The Java project is a Utility Billing System developed with Spring Boot. It manages customers, meters, meter readings, tariffs, bills, payments, users, authentication, and notifications.

The project demonstrates layered backend architecture using controllers, services, repositories, DTOs, entities, Spring Security, JWT authentication, JPA persistence, PostgreSQL integration, and Swagger/OpenAPI documentation.

### 3. Mobile Practical

The mobile project is LexiTech Dictionary, a cross-platform dictionary application built with React Native and Expo. It allows users to log in locally, search English words, view meanings and examples, play pronunciation audio, and save user-specific search history.

The app uses the Free Dictionary API, local AsyncStorage, drawer navigation, reusable UI components, TypeScript models, and structured screens for home, history, profile, login, and logout.

### 4. DSA Practical

The DSA project is a Smart Parking Management System written in C++. It provides a console-based system for configuring parking slots, registering vehicle entry and exit, calculating fees, updating parking rates, viewing parked vehicles, and saving reports.

It demonstrates practical use of data structures, object-oriented programming, file handling, input validation, and menu-driven program design.

### 5. Robotics Practical

The robotics project is a Face Recognition and Face Locking System for IoT-based servo control. It detects and recognizes faces, locks onto a selected identity, tracks movement, and sends control messages to an ESP8266 device through MQTT.

The system combines computer vision, face recognition, MQTT communication, servo control, and a real-time web dashboard for monitoring face tracking and lock status.
